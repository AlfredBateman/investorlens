InvestorLens — Setup & Run Instructions
========================================

What this is
-------------
InvestorLens is a local UX-research management app: projects, interviews,
personas, findings, recommendations, and journey maps, plus a dashboard,
search, filters, a printable report, and an optional AI transcript-analysis
feature. It runs entirely on your machine — the database is a single SQLite
file. No PostgreSQL, no Docker, no cloud account required to get started.

These instructions assume you have never seen this project before.


1. Prerequisites
-----------------
- Node.js v20.9 or later (check with: node --version)
- npm (comes with Node)

Nothing else. No database server, no Docker.


2. Install dependencies
------------------------
From the project's root folder, run:

    npm install

This also generates the Prisma database client automatically (a
"postinstall" script runs `prisma generate` for you).


3. Set up your environment file
---------------------------------
Copy the example file:

    cp .env.example .env          (macOS/Linux)
    copy .env.example .env        (Windows)

You do not need to edit .env to run the core app — every variable in it is
optional. See "Optional: AI transcript analysis" below if you want that
one feature.


4. Create the database
------------------------
This creates the SQLite file (prisma/dev.db) and applies the schema:

    npx prisma migrate dev

You'll be prompted for a migration name only if you've changed the schema
yourself; running it as-is against a fresh checkout just applies the
existing migrations.


5. Load the sample data
--------------------------
This fills the database with a complete demo research project — 14
interviews, 3 personas, 5 findings, 8 recommendations, and 1 journey map:

    npx prisma db seed

Re-running this command wipes and reloads the sample project. Don't run it
if you've entered your own data you want to keep.


6. Start the app
-------------------
    npm run dev

Then open your browser at:

    http://localhost:3000

That's it — you should land on the dashboard for the seeded "Retail Investor
UX Research" project.


7. Optional: AI transcript analysis
--------------------------------------
There's an experimental feature at /ai/transcripts that sends interview
transcript text to Google's Gemini API to suggest candidate findings. It is
OFF by default and invisible in the nav until you enable it.

To turn it on:

  1. Get a Gemini API key from https://aistudio.google.com/apikey
  2. Open .env and set:

         AI_FEATURES=on
         GEMINI_API_KEY=your-actual-key-here

  3. Restart the dev server (Ctrl+C, then npm run dev again)

If AI_FEATURES=on but GEMINI_API_KEY is missing, the page explains this
instead of showing the transcript form — it will not silently fail.

Privacy note: any transcript text you submit through this feature is sent to
Google's servers. Don't paste real participant data unless you're authorized
to share it externally.


8. Production build (optional)
---------------------------------
    npm run build
    npm run start

This builds and serves the optimized production version on port 3000.


Quick reference (all commands in order)
------------------------------------------
    npm install
    cp .env.example .env
    npx prisma migrate dev
    npx prisma db seed
    npm run dev


Troubleshooting
-----------------
"Cannot find module better-sqlite3" or Prisma client errors:
    npm install
    npx prisma generate

Data seems missing or wrong:
    npx prisma db seed

Reset the database completely (deletes all data, including anything you
entered yourself):
    npx prisma migrate reset
    npx prisma db seed

Port 3000 already in use:
    npm run dev -- -p 3001
    (then open http://localhost:3001 instead)

/ai/transcripts shows "not found":
    You haven't set AI_FEATURES=on in .env, or you didn't restart the
    server after changing it.

Gemini requests fail with "API key not valid":
    Your GEMINI_API_KEY is missing, wrong, or has extra whitespace/quotes
    around it in .env.
